# 工作台图片出题

工作台顶部新增「图片出题」。选择年级、科目、知识点和题型，可设置每种题型的题量、难度、画面风格与补充要求，一次选择生成 1～10 张 PNG 习题图。题型及题量按每张图片计算，每张上限为 24 道题、5 种题型。

后端根据这些条件直接构造图片提示词，由生图模型自主设计完整画面；不经过 JSON 题目生成、HTML 试卷渲染、卷面模板或截图导出。多张生成时，提示词包含总张数和当前序号，要求每张独立成图、变化题目与情境。生成前可预览第一张提示词，结果支持逐张切换、放大、下载和查看每张实际提示词。AI 图片中的文字和题目需要人工核对。

「下载 PDF」按原始顺序合并当前已完成的图片，一张图片一页。每页使用适合图片方向的 A4 纸，等比居中、四周至少留白 5 mm，完整保留图片，不裁切、不增加封面或空白页。直接嵌入 PNG，避免截图或 JPEG 压缩造成文字模糊；PDF 在浏览器本地合成，不上传图片、不重复调用生图接口。导出库按需加载。

管理员生成图片后，可直接点击预览区的「添加到后台」，确认习题标题、年级、科目并选择分类，将本批已完成的图片合成一份 PDF，保存为公共习题草稿。年级、科目和标题取自这批图片的生成条件，修改左侧下一批的出题条件不会影响它们。保存后点击「查看后台草稿」即可预览、调整权限并发布，无需先下载再手工上传。此操作复用后台 PDF 导入接口，生成预览页并持久保存文件，不再调用生图服务；单份 PDF 上限为 32 MB。保存结果不明确时可先查看后台，同一弹窗重试复用原 PDF，避免重复归档。

## 接口配置

先构建并更新运行服务中的后端、`web/dist` 和 `admin/dist`，再进入管理后台「模型配置 → 图片生成服务」填写：

- 接口地址：自定义 OpenAI 兼容基础地址，例如 `https://example.com/v1`；也接受完整的 `/images/generations` 地址。无路径的域名自动补 `/v1/images/generations`，自定义路径保留。
- 模型：服务商提供的生图模型 ID，与文本模型独立。
- API 密钥：服务端加密保存，读接口不返回明文。留空保留现有密钥；清除生图配置会删除已保存密钥。
- 图片尺寸：必须匹配模型支持的值，默认 `1024x1536`。也可填 `1024x1792`、`1024x1024` 或 `auto`，以接口文档为准。
- 返回格式：默认「自动」，不发送 `response_format`；可显式选择 `b64_json` 或 `url`。
- 超时：30～600 秒，默认 300 秒。若部署使用额外网关或反向代理，请确保允许该接口等待相应时长；客户端等待上限为 630 秒。

请求使用 `POST /images/generations`，发送 `model`、`prompt`、`n: 1`、`size`，按配置附加 `response_format`。多张采用逐张顺序请求，兼容只支持 `n: 1` 的服务商，并逐张展示进度。支持同步返回的 `data[0].b64_json` 或 `data[0].url`；不支持服务商另行定义的异步任务协议。

URL 图片须为公开 HTTPS 地址。服务端逐次验证并固定公网 IP，不转发 API 密钥给图片下载地址。图片经格式、大小、像素限制及 PNG 转换后交给浏览器，保证下载不依赖远端链接的跨域配置或有效期。

## 请求与结果

- 图片生成与现有题目生成共用登录权限、请求额度、并发限制、请求 ID 去重和结果查询机制。每张占用一次请求额度，并可能分别产生服务商费用。
- 每张图片保留独立请求 ID，同 ID 重放不会再次调用服务商。中途失败会停止后续生成，保留之前成功的图片。超时和网络错误不会自动重发；先「查询本次结果」，再由用户主动「继续生成剩余 N 张」。重试失败图片会使用新的请求 ID，已成功的图片不会重新生成。
- 「暂停后续生成」等待当前图片完成后停止。刷新或重新打开页面只查询已发出的请求，不自动生成剩余图片。用户点击继续后才恢复队列。
- 同一页面切换到试卷搭建再返回，会保留图片。浏览器按账号保存本批出题条件、各张请求 ID 和状态，刷新后可恢复；兼容之前的单张请求记录。图片内容不会存入 localStorage。
- 新图片保存为私有文件，`generation_requests.result_json` 只存资产 URL、尺寸和元数据；文件接口校验当前账号。默认每用户 `IMAGE_STORAGE_MB=512`，与 `GENERATION_RESULT_DAYS`（默认 7 天）同步过期，由独立维护任务分批清理。原请求记录保留以防重复调用。旧 Base64 结果仍可恢复；浏览器 IndexedDB 改存 Blob，localStorage 仅保存请求状态。单张图片限 12 MiB，服务商响应限 18 MiB，最大 1600 万像素。详见 [优化交付记录](optimization-2026-09-21.md)。
- 「添加到后台」仅对管理员显示，保存为草稿；在后台检查并发布后，小程序才可见。普通工作台用户仍可下载 PNG 或 PDF。

pnpm --dir web typecheck
pnpm --dir web test
pnpm --dir web build
pnpm --dir admin typecheck

`tests/ui_fixture.py` 为图片出题提供离线测试图片，明确标注 `OFFLINE IMAGE FIXTURE - NOT AI OUTPUT`，不调用任何真实生图接口。实际服务商的模型、尺寸支持、文字质量和费用需在配置真实接口后验收。
