## 行为与安全边界

- 批量操作只处理当前账号的收藏；单次最多 200 份，对应现有列表窗口上限。“全选已加载”不会误选未加载的资料。
- 取消收藏需要确认，不删除下载记录。失败保留勾选，可重试或刷新；分组不存在、收藏已被其他操作取消时会显示服务端错误。
- 分组写入使用现有账号事务锁。目标分组归属和全部收藏存在性校验通过后才写入，避免部分成功。
- 页面离开、账号切换后，迟到的读取和操作结果不会覆盖新页面。确认弹窗期间切换账号不会执行旧操作。
- 草稿只保存在当前设备，以账号 ID 隔离，保留 7 天。只存资料名称、年级、学科和补充说明，并限制字段长度。
- 草稿在输入后延迟保存，隐藏或退出页面时立即保存；存储失败显示重试入口。提交成功后清空所有字段及本地草稿。
- 客服跳转参数只接受 `contact=1`，继续使用现有安全回跳白名单。

## 接口与发布顺序

新增 `POST /api/v1/mini/favorites/batch`，请求体为：

```json
{
  "ids": ["catalog-id"],
  "action": "assign",
  "group_id": "owned-group-id"
}
```

`action` 支持 `assign`、`remove`；移回未分组使用 `assign` 加 `group_id: null`。取消收藏不接受非空分组。

`GET /api/v1/catalog/papers` 增加 `ungrouped=true` 查询参数。生成的共享 API 类型已同步。本轮不改数据库结构，不需要新增迁移。

发布时应先更新后端，再上传小程序；否则新客户端的批量收藏接口会返回 404。H5 本地开发代理连接旧后端时，只能预览新界面，不能据此判断新接口已上线。

## 真机验收

H5 回归和小程序编译不等同于微信真机验证。发布前仍需在微信开发者工具及 iOS、Android 真机确认：

- 刘海屏、安全区、微信胶囊按钮与底部操作栏。
- 双指缩放、缩放后拖动、恢复适宽、横滑翻页及缩略图跳页。
- 原生年级、学科选择器与软键盘弹出时的表单布局。
- 后台返回、弱网重试、草稿恢复、系统相册返回、原生 PDF 下载和打开。

这些是平台验收边界，不是已经完成的线上验证。
