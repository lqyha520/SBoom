# 推广运营与财务中心六项优化验收

日期：2026-11-12。六项优化已完成代码、数据库迁移及回归验证，并部署到 WSL 与线上；部署版本、实际网站检查和备份回退信息见[本次发布记录](promotion-six-release-2026-11-12.md)。

| 优化项 | 实际行为与入口 |
| --- | --- |
| 成本完整性 | 活动详情、投入明细区分已知小计与完整累计。历史成本未知时不计算结余和回报率；确认无历史投入可填 0。 |
| 查询与导出一致 | 推广用户、订单导出使用最后成功查询的范围；修改条件但尚未查询时禁用导出并显示提示。 |
| 付款前预检 | 付款管理提前显示收款资料、批次占用、业务状态和独立付款限制；跨页选择显示合计，可刷新与移除问题单据，提交仍重新校验。 |
| 原始凭据 | 成本台账和活动投入区可登记凭据总额、上传附件；跨活动及订单分摊受总额限制，并发提交超额时整笔回滚。 |
| 同周期比较 | 推广概览展开同周期活动对比，查看本期与相邻等长前期的投入、付费、退款等指标，支持排序及分页。 |
| 月末清单 | 财务工作台汇总待留档、微信对账、成本附件、未结束异议，按职责过滤，并携带月份、日期或对象跳转办理。 |

## 数据口径

- 凭据的成本归集与奖励扣费分别封顶，两者不相加；历史未登记原始凭据的编号暂不参与总额校验，补登记时核对既有分摊。
- 同周期投入包括有发生日期的有效历史补录，累计不会重复增加。历史累计未全部补录日期时，不计算每位付费用户投入。该指标包含续费用户。
- 月末清单显示当前尚未处理的事项，不改写已留档月账。微信对账以该日期最新一条结果为准。
- 数据库版本为 `2026111203`，新增原始凭据及附件表；附件随 PostgreSQL 备份保存，不重算历史奖励或付款。

详细规则见 [推广结算说明](promotion-settlements.md)。
