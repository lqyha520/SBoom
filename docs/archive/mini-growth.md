# 小程序功能扩展

本轮在[小程序与运营后台优化](../mini-optimization.md)的基础上，完成资料与专题分享、登录返回、教学标签、消息与需求、打印版本、注销申请，以及可配置的会员支付、订单、退款和对账。验收日期：2026-09-16。

用户选择“尚未开通收费渠道，先完成可配置代码和测试”。因此支付与微信订阅提醒默认关闭，不预置已上架套餐；真实商户接入、真机实付和发布仍须在取得相应配置后验收。

## 操作入口与规则

| 功能 | 小程序入口 | 后台入口 |
| --- | --- | --- |
| 分享、专题 | 首页、资料详情和专题页的微信分享；登录后回原目的地 | 专题合集编排标题、说明与资料 |
| 教学标签 | 习题库 → 筛选；详情展示标签 | 教材与知识点；公共习题 → 标签与打印 |
| 私人消息 | 首页未读提示；我的 → 消息中心 | 服务与反馈、资料需求、会员与支付等操作产生结果消息 |
| 资料需求 | 搜索无结果 → 提交资料需求；我的 → 资料需求 | 资料需求 → 汇总需求、安排、回复、关联已发布资料 |
| 打印版本 | 资料详情 → 打印版本 → 下载 PDF | 公共习题 → 标签与打印 → 关联同题目的归档 |
| 注销 | 我的 → 账号设置 → 注销账号 | 注销申请 → 审核；通过时须输入当前账号名称 |
| 套餐、订单、退款 | 我的 → 会员服务 / 我的订单 | 会员套餐、会员订单 |
| 对账、发送状态 | 在订单和消息页查看自己的处理进度 | 账单核对、订阅提醒 |

分享仅包含公开标题、允许的目的地与本地通用图片，不带 token、OpenID 或受限原稿。登录返回采用页面和参数白名单，拒绝外部 URL、私人归档目的地与异常嵌套参数；底部页面使用 `switchTab` 返回。

每份资料可关联一个教材、一个学期、一个单元及最多 20 个知识点。隐藏标签保留关联，但不在小程序展示。筛选中的教材、学期、单元、知识点可组合使用。

资料需求按账号隔离，每天最多新增 5 条；重复未结需求复用原记录。后台按名称、年级、学科汇总人数及待处理量，补齐时只能选择可见的已发布资料。搜索词、年级和学科自动带入表单。消息链接直接读取本人对应记录，不受第一页分页范围限制。

练习版、答案版需由管理员在工作台导出并保存，系统验证题目指纹、导出模式和文件就绪状态，不把不同题目的文件配在一起。源文件选择器匹配最近 500 份同年级、学科、题量的归档，最多返回 50 份，可用搜索缩小范围。关联和历史引用会阻止误删源文件；资料修订后重新关联版本，旧消费文件链接不再授权。

站内消息保留 180 天，事件去重，支持逐条已读、全部已读和仅看未读。切换账号时清空本地未读状态。微信提醒使用同一条业务结果，需用户主动接受一次订阅，才增加一次发送额度。

注销申请和审核通过时都会再次检查订单、退款是否结清，防止提交后发生新交易而误删。完成注销会删除个人资料与消费记录，移除加密 OpenID，交易记录解除账号关联后保留用于核对。注销本身不触发退款。

## 会员与财务处理

- 套餐初始未上架；名称、说明、天数、精确到分的价格和顺序由管理员填写。套餐修改不会改写已下单的金额和权益快照。
- 下单使用幂等请求标识、服务端价格和短期支付窗口。微信支付成功界面不能直接开通会员；服务端验证签名，以及商户、AppID、付款人、金额、币种和交易时间后才确认到账。
- 会员授予、查询、关闭订单、退款和回调支持去重及并发保护。到期时间仍以服务端为准，长期会员无需重复购买。
- 退款支持整单原路退款，管理员审核后向微信提交，以微信最终结果为准。成功后仅移除本订单尚未使用的时长，保留其他订单与人工续期；人工绝对调整会员状态也有独立保护。
- 当前每笔订单保留一次全额退款申请。申请被拒、退款关闭或异常时，通过客服和商户平台进一步处理；不提供部分退款、自动续费或自动重新申请。
- 对账按北京时间，支持昨天至最近 90 天的微信交易账单。分别获取收款、退款账单，验签并校验下载哈希，保留本地与微信差异、金额汇总及核对记录。
- 对账用于交易核对，不等于银行结算或开票，不会自动修改订单和会员。商户平台直接退款、账单差异及异常退款需要人工核对。订单 CSV 支持状态、账号、日期筛选，单次最多 5000 笔，并处理公式注入风险。

## 服务端配置

所有新增配置见[环境变量模板](../../.env.example)。密钥仅在服务端私有目录及环境配置中管理，不在小程序、后台表单、静态目录或 Git 中保存。保留稳定的 `SECRET_KEY`，供已加密数据在重启或多实例间正常解密。

| 配置 | 用途 |
| --- | --- |
| `WECHAT_APP_ID`、`WECHAT_APP_SECRET` | 与小程序一致的真实微信登录配置；旧账号需重新微信登录以保存加密 OpenID |
| `WECHAT_PAY_ENABLED=false` | 支付总开关；未启用或配置不完整时不创建在线支付订单 |
| `WECHAT_PAY_MCHID` | 已开通相应支付能力且绑定 AppID 的商户号 |
| `WECHAT_PAY_SERIAL_NO`、`WECHAT_PAY_PRIVATE_KEY_PATH` | 商户证书序列号与 RSA 私钥路径 |
| `WECHAT_PAY_PLATFORM_SERIAL`、`WECHAT_PAY_PLATFORM_KEY_PATH` | 微信支付公钥编号及公钥路径，或平台证书序列号及证书路径 |
| `WECHAT_PAY_API_V3_KEY` | 32 字节 API v3 密钥，用于验证后的回调解密 |
| `WECHAT_PAY_NOTIFY_ORIGIN` | 公网 HTTPS 源地址，不含路径；后台显示完整回调地址 |
| `WECHAT_PAY_IOS_ENABLED=false` | 取得实际类目、平台准入及支付能力后才启用 iOS 开通 |
| `WECHAT_PAY_AUTO_RECONCILE=false` | 支付启用后，可选择北京时间 10:00 后自动核对昨日账单 |
| `WECHAT_SUBSCRIBE_TEMPLATE_ID` | 已申请的服务通知模板，留空时不启用微信提醒 |
| `WECHAT_SUBSCRIBE_TITLE_FIELD` | 模板标题字段，`thing` 或 `phrase` 类型 |
| `WECHAT_SUBSCRIBE_BODY_FIELD` | 模板正文字段，`thing` 类型 |
| `WECHAT_SUBSCRIBE_TIME_FIELD` | 模板时间字段，`time` 或 `date` 类型 |

支付回调为 `/api/v1/payments/wechat/notify`，退款回调为 `/api/v1/payments/wechat/refund-notify`，必须支持微信访问。成功响应及回调均验签，回调进行 AES-GCM 解密；密钥格式不支持、证书不匹配或过期均视为配置未就绪。

微信登录保存的是服务端加密 OpenID，小程序只收到 `has_wechat` 状态。H5 不提供微信支付；未配置、账号尚未完成微信绑定及默认 iOS 场景显示明确提示。订阅也仅在微信端主动授权后登记额度。

维护任务随应用生命周期启动、停止，只在支付或订阅配置启用时运行；处理超时订单、退款、会员提醒、发送队列和可选对账。操作使用数据库租约及去重；发送结果未知时不盲目重发，用户仍可在站内查看完整结果。

## 数据与验收环境

账号仍独立于出题工作台。新增 engagement / commerce 数据结构采用 SQLite、PostgreSQL 增量迁移，不清空旧表、不自动发布资料、不默认上架付费套餐。已有自定义协议不会被默认文案覆盖；正式启用前需在后台核对运营主体、联系信息和当前数据处理说明。

功能开发阶段未部署或提交 Git；后续按用户要求备份本地数据库，恢复日常服务并运行增量初始化。临时 UI 服务使用独立 SQLite、临时文件和测试账号；支付全部经过带签名的 `httpx.MockTransport`，没有调用真实支付、退款或微信消息发送。该替换仅存在于 `tests/`。

可重复验收命令：

```powershell
py -3.12 -m unittest discover -s tests -p 'test_backend*.py' -v
py -3.12 tests/run_growth_postgres.py
py -3.12 tests/run_ui_contracts.py
pnpm --dir admin typecheck
pnpm --dir admin build
pnpm --dir miniprogram test
pnpm --dir miniprogram typecheck
pnpm --dir miniprogram build:h5
pnpm --dir miniprogram build:mp-weixin
pnpm --dir miniprogram check:mp
```

浏览器手工验收先准备 `artifacts/miniprogram/demo/manifest.json`（生成方法见小程序 README），构建 admin 和 H5，再使用空闲端口运行：

```powershell
py -3.12 tests/growth_ui_fixture.py --port 8317 --seconds 900
```

小程序地址为 `http://127.0.0.1:8317/`，后台为 `/admin/`。它提供教材标签、同题答案版、两人重复需求、消息、未付款订单和待审核退款，费用和账号均为测试数据。进程到期或正常退出后清理临时目录。双库验证脚本只创建并移除自己拥有的临时容器，不操作 `learncoach-db` 或现有数据卷。
