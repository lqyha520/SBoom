# 小程序验证清单

常规本地入口：[小程序预览](http://127.0.0.1:5180/) · [管理后台](http://127.0.0.1:8000/admin/)，需先启动对应服务。后端修改需要重启服务，微信端修改需要重新编译小程序。小程序账号与管理后台账号独立，使用各自原有账号登录。

## 先验证这次修复

| 操作 | 应看到的结果 |
| --- | --- |
| 未登录打开首页 | Banner、学科入口、精选、上新、专题正常展示，不强制登录 |
| 未登录进入习题库，搜索、切换学科、打开筛选 | 可以按年级、分类、教学标签筛选，加载更多及查看公开资料 |
| 未登录打开免费习题 | 能查看详情和原稿预览；按钮显示“登录后下载” |
| 未登录打开 VIP 习题 | 能看标题和分类等公开信息，完整内容继续显示会员限制 |
| 未登录点击收藏或下载 | 进入登录页，登录成功后回到所选习题；再次操作即可收藏或下载 |
| 未登录打开收藏、消息等个人页面 | 显示登录入口，不展示其他用户的数据 |
| 登录 → 我的 | 顶部直接显示头像与资料，没有“我的”大标题或右上角设置按钮；账号与安全入口位于页面下方 |
| 登录 → 我的 → 点头像或“编辑资料” | 头像预览、微信选图入口与 5 个默认头像（小狐狸、小熊猫、小企鹅、小鹿、小兔子），选中状态清晰 |
| 新微信号首次登录 | 固定账号为 wx 加 10 位数字，默认昵称为 2-4 个中文字；重复登录不会改名或重建账号 |
| 网页注册或后台创建账号 | 新账号仅允许 2-32 位英文、数字、下划线与短横线；历史中文账号仍能登录 |
| 将昵称改为“小明 😀”或单字昵称，保存后刷新 | 出现“资料已更新”，刷新后仍显示新昵称，原登录账号和密码保持有效 |
| 网页端选择 JPG / PNG / WebP 图片（原图不超过 20 MB），保存并刷新 | 自动裁剪压缩后上传，头像立即回显，刷新或重新登录后仍能看到 |
| 微信选择头像或打开相册再返回 | 编辑弹层和昵称草稿保留；图片处理完成后可以保存 |
| 上传失败后再次保存 | 保留已选图片和昵称，显示可读错误，可直接重试 |
| 编辑时选择图片或改昵称，然后关闭表单 | 未保存的修改不会更新账号 |
| 编辑资料 → 选择任一默认头像 → 保存 | 显示选中的头像；之前上传的图片不再作为当前头像提供 |
| 我的 → 会员服务 | 首屏显示联系客服，底部始终保留客服入口；套餐先选择再确认，不在点选时直接下单 |
| 会员服务 → 咨询开通 / 联系客服 | 就地打开联系面板，可复制微信和邮箱、拨打电话、查看二维码或留言；没有配置联系方式时仍能留言 |
| 会员服务 → 输入卡密 → 兑换 | 错误显示在输入框下方且保留输入；成功后显示增加的天数和新到期日；长期会员不再显示重复兑换入口 |

微信端请重新编译小程序后，进入“我的 → 编辑资料”：点击“使用微信头像”，在微信面板里主动选择头像，然后保存。昵称输入框支持微信昵称选择。这里采用微信的 `chooseAvatar` 能力，不会在登录时自动读取头像。网页 H5 无法弹出微信授权选择面板，因此显示“选择头像图片”。

当前代码和构建已验证，微信真机的选择面板、隐私提示及头像回传还需要在真实微信运行环境确认。现有微信开发构建使用 `pnpm --dir miniprogram dev:mp-weixin`，在开发者工具导入 `miniprogram/dist/dev/mp-weixin`；正式包使用真实 AppID 和 HTTPS API 配置。

| 资料需求 | 管理员打开“资料需求” | 登录后搜索一个无结果关键词 → 提交资料需求；关键词、年级、学科带入；后台回复后“我的 → 资料需求”看到状态和结果 |

| 批量发布与资料修订 | “公共习题”批量设置分类、权限；针对资料发布新版本 | 公共列表更新；原收藏和详情入口保留，详情显示版本说明，文件切换到新版本 |
