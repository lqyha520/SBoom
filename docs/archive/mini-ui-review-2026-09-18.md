# 小程序 UI 与交互评估（2026-09-18）

> 下文为改动前的评估记录；本轮代码优化已实施，完成情况与验证结果见文末。

本次检查当前源码，并使用本机 H5 预览实际查看首页、习题库、筛选面板、资料详情和原稿预览；详情另检查了 320px 窄屏。个人中心及分享、下载等逻辑以源码检查为主。没有进行微信真机分享、支付或原生 PDF 验收，也没有修改业务代码。

现有绿色主题、卡片、四栏导航、加载与空状态可以保留。优先修正操作行为，再提高信息可读性与找资料的效率。

## 优先修复：行为与用户预期不一致

### 1. 列表侧滑松手就执行操作

- 证据：`miniprogram/src/components/SwipeAction.vue:30`、`:40`、`:57`。
- 当前以横向距离选择操作，超过 40px 后松手就触发收藏、下载或分享，没有先展开按钮再确认点击；也没有比较纵向位移，斜向滚动有误触风险。
- 操作区从右侧露出，最右侧是“分享”，但左滑 40–79px 的距离判断选中的是“收藏”；滑到最大 240px 时索引变成 3，又不会执行任何操作。
- 建议：只用侧滑展开操作区，点按钮才执行；增加横纵方向判定、取消手势、单行展开和忙碌状态保护。“收藏”根据实际状态显示“取消收藏”。
- 验收：上下及斜向滚动不改变收藏或跳转；轻滑、完整展开、关闭和点击的行为一致。

### 2. 搜索防抖没有覆盖输入路径

- 证据：`miniprogram/src/components/CatalogList.vue:65`、`:136`、`:196`。
- 输入框直接绑定 `q`，同步 watcher 在每次输入变化时调用刷新；300ms 防抖只包裹显式搜索函数。逐字输入仍会逐次请求，按确认搜索还可能重复刷新。
- 筛选提交逐个赋值也会多次触发同步 watcher；刷新还会重新请求分类、专题和教学标签。
- 建议：分开输入草稿和提交查询，输入停顿后统一检索、确认键立即检索；筛选一次提交；元数据独立加载并缓存。列表已有内容时使用局部加载提示。
- 验收：快速输入一段关键词只提交最终查询；提交多项筛选只发起一次列表检索；离开页面后不执行遗留搜索。

### 3. 列表“分享”和“下载”需要补齐真实行为

- 证据：`miniprogram/src/components/PaperRow.vue:14`、`miniprogram/src/components/CatalogList.vue:173`。
- “下载”实际只进入详情，没有启动下载；可以改名为“查看资料”，或进入详情后明确呈现文件选择。
- 列表分享使用 `uni.share`，微信小程序应通过用户点击 `open-type="share"` 按钮和页面 `onShareAppMessage` 提供分享内容；H5 的当前处理函数没有行为，却仍提供该操作。
- 建议：修复现有单份资料分享入口，平台不支持时隐藏或给出明确替代操作。分享公开资料链接；私人收藏或下载记录本身不应作为默认分享目标。
- 验收：微信点击分享得到当前资料的正确标题与路径；H5 不出现点击无反馈的分享按钮。

## 优先改善：阅读与查找效率

### 4. 压缩首页引导区，让资料更早出现

- 实际预览中，没有运营 Banner 时仍展示大号欢迎卡，标题“找到今天想练的那一份”末尾单字换行；叠加学科入口和两行公告后，首屏资料标题已靠近底部导航。
- 证据：`miniprogram/src/components/HomeBanner.vue:39`、`:101`。
- 建议：无运营内容时改用紧凑引导；公告默认摘要、点击查看全文；优先让用户看到完整资料标题及标签。回访用户可以展示最近浏览资料入口，保留现有年级偏好。
- 验收：375px 手机宽度下标题不出现尴尬断行；常见屏高首屏能看清至少一组推荐的标题和元信息。

### 5. 统一字号和控件点击范围

- 首页卡片元信息为 11px，个人中心服务说明为 9px，会员权益为 10px。
- 证据：`miniprogram/src/components/PaperCard.vue:37`、`miniprogram/src/pages/account/index.vue:197`、`:205`。
- 建议：正文 14–16px、辅助说明 12–13px；压缩冗余文案以容纳更大字号。年级、筛选、排序等操作尽量保持至少 44px 点击范围。
- 弹层圆角目前有 8px、22px、24px 多种取值，可以统一同类底部弹层的圆角、标题、关闭按钮和底部操作区。
- 验收：320/375/430px 与系统大字体下查看长标题、服务说明、筛选及弹层按钮；不能只检查是否横向溢出。

### 6. 将常用筛选与高级筛选分开

- 年级入口和筛选图标打开同一个长面板；面板依次包含年级、分类、教材、学期、单元、知识点。标签选项目前仅按种类过滤。
- 证据：`miniprogram/src/components/CatalogList.vue:196`、`miniprogram/src/components/CatalogFilterSheet.vue:22`、`:42`。
- 建议：年级入口提供快速选择；“更多筛选”收纳高级条件，没有可选项的字段不占位置。若增加年级/科目/教材联动，需要先补齐标签关联数据。保留已选条件标签与清除入口。
- 滚动较长列表时可固定紧凑搜索与筛选条，避免每次改条件都回到顶部。

### 7. 导入资料的“0 题”应有合理兜底

- 实际列表中的“二年级每日练习题彩色版”显示“0 题 · 5 页”，首页也展示“数学 · 0 题”。详情已按非零值隐藏题数，三处规则不一致。
- 证据：`miniprogram/src/components/PaperRow.vue:36`、`miniprogram/src/components/PaperCard.vue:21`、`miniprogram/src/pages/paper/index.vue:193`。
- 建议：题数未知时隐藏题数，优先展示页数和文件类型。区分“可免费预览”“VIP 下载”“免费 PDF”“网盘资料”，统一卡片与详情措辞。
- 后续数据层最好区分“未统计题数”和真实零值，避免把缺失数据当作内容结论。

### 8. 详情主操作应提前说明权限及文件版本

- 实际预览中，带“VIP 下载”标签的资料对游客仍显示“登录后下载”，文件说明也是“登录后可下载”。用户登录后才会在主操作中看到会员限制。
- 证据：`miniprogram/src/pages/paper/index.vue:200`、`:204`、`:208`。
- 建议：主按钮旁持续显示“可免费预览，下载需 VIP”等准确说明；结合登录状态调整动作文案。多版本资料把练习版/答案版选择靠近底部下载操作，并在按钮或相邻说明中标明当前版本。
- PDF 已有进度及失败重试，重点补充原生打开后的保存/转发提示，并区分“打开文件”和“已保存到设备”。网盘资料继续明确提示需去浏览器或网盘 App 打开。

## 后续增强

- 游客收藏页目前是通用“登录习题库”空态，可以改为解释收藏的用途，并同时提供“去登录”和“先逛习题库”，减少被拦住的感觉。
- 列表元数据请求使用一个 `Promise.all`，其中一项失败会进入列表错误提示；可参考首页独立容错，让专题或标签失败不影响已经成功显示的资料。
- 缩略图可按进入视口延后获取。`PrivateImage` 当前在挂载时就申请文件，仅给 `<image>` 加 `lazy-load` 不能阻止此前的文件请求；需要调整文件获取时机，并测量后确认收益。
- 统一自定义点击区域的按压反馈，并在微信真机验证。已有按钮反馈应保留，避免只靠增加动画或震动补偿交互不清楚的问题。
- 当前本机数据仍有“这是一条测试公告”和标题末尾“1111”等内容，正式展示前应由运营整理；本次未更改数据。

## 第二轮：弱网、长列表与阅读交互修复

用户确认“都修”后，已完成以下五项：

- 登录恢复：网络异常和服务端临时故障保留本地凭证，账号页面提供“重新连接”，恢复后重新加载当前页面；明确的登录失效仍清理凭证。补充并发初始化和旧响应覆盖账号的保护。
- 长列表：追加加载失败在底部重试同一 offset，保留已加载资料；收藏只锁当前行的收藏操作，查看资料不受影响。收藏与分页独立，迟到的列表响应不能覆盖刚更新的收藏状态；筛选后回到结果开头。
- 原稿阅读：全屏阅读器提供横滑、双指缩放、上下页和指定页跳转，只挂载当前及相邻页的鉴权图片。按账号、资料和发布版本保存本机阅读位置，最多 50 份，不保存文件 URL。页码选择使用独立弹层，修复 H5 原生 picker 被全屏预览遮挡的问题。
- 消息跳转：点击立即打开内容；已读回执后台串行同步，重复点击不重复扣减，失败支持原地重试及再次进入时重试，账号切换后隔离旧请求。待同步队列仅保存在当前运行内存，退出应用后重新读取服务端状态。
- 收藏分组：详情弹层直接新建并归组；创建成功而归组失败时保留分组供选择重试。收藏页分组改为横向滚动，避免分组占据多屏。
