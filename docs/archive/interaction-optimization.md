# 功能与交互优化（2026-09-18）

## 已实现

| 场景 | 新行为 |
| --- | --- |
| 习题库收藏与返回 | 收藏就地更新；取消收藏仅移除当前收藏行。详情返回时重新校验已加载的分页，并恢复滚动位置。筛选或账号改变后重新加载。 |
| PDF 下载 | 显示准备、下载百分比、打开文件状态；网络失败可重新下载，保留所选打印版本。权限或资料失效时刷新详情。 |
| 发布表单依赖 | 分类、年级科目加载失败显示独立重试入口；保留已填内容，依赖未就绪时阻止提交。 |
| 编辑试卷 | 支持撤销、重做与快捷键；题目管理中可锁定、解锁、单题替换。减少题数不会移除锁定题；重新生成按每份试卷各自的锁题状态执行。 |
| 批量生成 | 每份显示排队、处理、完成、失败或待确认状态及耗时；可停止后续请求，保留完成结果，未发送部分可稍后补齐。 |
| 后台导航 | 模块、主要列表的搜索、筛选和页码写入 URL，支持刷新和浏览器前进后退；切换模块后返回保留列表条件。 |
| 数据看板 | 下载失败排行可直达资料检查；无结果搜索可进入工作台，由用户点击应用知识点后填入条件。 |

## 使用边界

- 撤销记录仅保留本次页面会话，最多 20 个快照，序列化总长度限制约 400 万字符；连续标题、样式调整合并为一步。完整版本恢复仍使用本机历史。整卷生成会重置编辑撤销记录。
- 生成中、排版中、账号变化或单题请求结果未确认时暂停撤销，避免丢失请求恢复记录。排版完成后可以撤销。
- 阅读理解的题目与文章关联，目前使用整道大题重新生成，不开放单题替换与锁定。
- 单题替换复用请求状态查询机制；失败保留原题，仍在处理的原请求不会重复发送。重复题会被拒绝。
- 停止后续任务不能取消已经发给模型的请求，这些请求仍可能计费；待发送部分保留在草稿中。刷新后通过补齐继续。
- 目录返回会重新请求已经加载的页数，以兼顾位置恢复与权限、资料状态更新。
