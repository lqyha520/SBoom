# 小程序与运营后台优化

范围：资料检索、会员服务、反馈处理、专题与内容修订、使用记录和统计，以及登录前协议访问、昵称与登录名分离。

本文保留第一阶段的范围和验收记录；后续新增分享、消息、教学标签及支付等功能见[功能扩展与验收](../mini-growth.md)。

- [x] 登录名保持不变；昵称独立编辑；未登录可读正式协议。
- [x] 按账号记住年级、科目、搜索记录；最新、热门、免费筛选。
- [x] 批量分类与上下架；专题合集；普通用户/VIP 发布预览。
- [x] 会员权益与联系入口、到期提示；快捷续期、到期筛选和操作记录。
- [x] 资料纠错、下载问题、会员咨询；后台回复、备注与处理状态。
- [x] 资料修订保留公共条目身份、收藏和下载记录；显示更新说明。
- [x] 最近浏览、收藏分组；活跃趋势、无结果搜索和下载失败统计。
- [x] 双库迁移、权限隔离、并发冲突测试；三端类型检查与构建；服务保持关闭。

实施边界：沿用独立消费者账号及原稿/PDF 授权；数据库仅做增量迁移。下载成功统计指客户端报告获取/打开文件，不等于已另存到设备。日常服务在修改前停止，验收使用隔离数据。

## 操作入口与规则

| 功能 | 小程序 | 管理后台 |
| --- | --- | --- |
| 检索与专题 | 习题库选择精选/最新/热门、仅免费、专题；首页展示专题合集 | 公共习题勾选后批量分类、发布、下架或改权限；专题合集编排顺序 |
| 会员服务 | 我的 → 会员状态，查看权益、7 天内到期提示、联系与咨询入口 | 小程序用户 → 快捷续期 / 操作记录；支持即将到期与已过期筛选 |
| 问题反馈 | 资料详情提交纠错或下载问题；服务与反馈查看处理结果 | 服务与反馈 → 回复、内部备注、待处理/处理中/已解决/已关闭 |
| 资料修订 | 原详情链接查看新版原稿及版本说明，保留收藏 | 公共习题 → 修订，选择自己保存的新归档并确认发布 |
| 收藏与浏览 | 收藏页创建、改名或删除分组；详情加入分组；我的 → 最近浏览 | 内容数据看板查看使用趋势及问题排行 |
| 身份与协议 | 编辑展示昵称；设置中查看固定登录名；登录前可读协议 | 可修改昵称、预设头像及账号状态；协议正文由运营方维护 |

- 热门按收藏人数与申请下载人数之和排序；最新按发布时间排序。仅免费在数据库分页前计算，要求有效观看和下载规则均免费，不受当前用户是否 VIP 影响。
- 搜索偏好在设备本地按账号隔离，最多 12 条历史；收藏分组最多 50 个，使用滚动面板选择，最近浏览最多 100 份。删除分组保留收藏，清空浏览记录不影响收藏或下载记录。
- 专题最多 100 份资料，按编排顺序显示；未展示专题、草稿、下架或文件未就绪的资料不会进入消费者专题列表。
- 单批最多 50 份资料。任一 revision 冲突即整体回滚；批量发布需要内容确认和文件就绪。客户端不会把旧请求结果覆盖到切换后的账号。
- 续期从有效会员原到期日累加；已过期和普通用户从当前时间计算。长期会员无需续期；续期不会解除禁用，旧 revision 重放不会重复增加天数。
- 每账号每小时最多提交 10 条反馈，限制存于数据库并供所有 worker 共用；纠错和下载问题必须关联可见资料。内部备注不包含在消费者响应中。
- 修订保留公共 ID、收藏、下载、专题及逐份权限；历史原稿不可直接重新加入公共库或删除。修订后消费者旧文件 URL 失效，之后获取新版；已另存文件不能远程更新。
- 使用趋势按北京时间汇总近 30 天，活跃用户按账号/日去重。事件滚动保留 60 天，记录新事件时清理过期数据；启用前的活动不补算。下载结果由客户端报告，不作为付款或设备存档凭据。

## 升级与复验

后端下次启动时执行增量建表/加列，已有账号和公共条目保留。`nickname` 初始取旧登录名；已有昵称不会被后续启动覆盖。旧客户端资料编辑中的 `username` 字段兼容为修改昵称，固定登录名不改变。

内置协议默认值及离线说明已补充浏览记录、反馈和统计范围；数据库中的已有协议保持运营方配置，应通过后台核对新功能对应的说明。会员联系信息在「服务与反馈 → 会员与联系设置」中配置。

```powershell
py -3.12 -m unittest discover -s tests -p 'test_backend*.py' -v
py -3.12 tests/run_ui_contracts.py
pnpm --dir admin typecheck
pnpm --dir admin build
pnpm --dir miniprogram test
pnpm --dir miniprogram typecheck
```

可选 PostgreSQL 复验：将 `LC_TEST_PG_DSN` 设为本机临时数据库的 PostgreSQL URI（数据库名必须以 `lc_verify` 开头），然后运行 `py -3.12 -m unittest discover -s tests -p postgres_experience.py -v`。不要指向业务库。
