# 小程序性能优化 · 2026-10-13

本轮处理选页原图下载、资源排队、登录恢复重复请求、临时文件容量、长资料渲染和目录连续分页，并修正详情难度字段。

## 行为与边界

- 上传归档时为每页生成 320×480 以内、JPEG quality 82 的缩略图，沿用 `paper_assets` 的 `(paper_id, kind, page_number)` 唯一约束。详情中的 `page` 资源增加 `thumbnail_url`，缩略图不增加 `assets` 页数。缩略图接口沿用资料的实时预览权限。
- 历史页图由 `maintenance.backfill_thumbnails` 每轮最多 5 页补齐，使用新的 `page_thumbnail_backfill_*` 游标；完成扫描后次日重新检查失败项。补图遵守存储配额，删除资料后派生文件由原有保留任务清理。无需数据库迁移；部署服务代码后需保持维护任务运行。补齐前选页显示页码，仍可打开原稿。
- 下载队列最多 4 个并发，其中普通图片最多 3 个。优先级为 PDF、当前阅读页、普通图片、预取/运营图。不会中断其他消费者正在使用的下载；已排队的预取可升为当前阅读页并复用同一请求。轮播仅持有当前与下一张。
- 图片空闲缓存上限为 12 MiB / 40 个 / 45 秒；PDF 独立为 32 MiB / 1 个 / 10 秒。大小使用传输进度与 PDF 文件元数据，未知大小不缓存。预算针对空闲临时文件或 H5 Blob，不是进程总内存；正在显示的图片和原生查看器仍持有的 PDF 不会被预算提前删除。
- 阅读器最多挂载 5 个 swiper item、3 张原稿图；滑动动画完成后才重新居中窗口。选页每组 12 项，打开时定位到当前页所在组。页码、阅读位置、适宽及缩放重置继续按实际页号处理。
- 仅 `/site/home`、`/site/topics`、`/site/catalog-tags` 的公共内容跨登录代际复用 60 秒缓存和在途请求，并始终匿名读取。权限、收藏、个人摘要仍按当前账号刷新。手动刷新可绕过缓存；取消最后一个读取者后仍会终止请求。
- 公共目录通过游标顺序分页和组间跳转，`include_total=true` 仅在刷新组首时请求总数；后续页使用 `has_more` 与 `next_cursor`。每组仍最多 60 行，返回时保留窗口与滚动位置并核验权限。筛选/账号切换清除游标；失效游标回到首组。个人活动列表保持原有 offset 方式。
- 详情展示顶层 `difficulty`，不再依赖公开接口已经移除的题目快照。

## 本地性能指标

`runtime.performanceSummary()` 与帮助与反馈中的“复制故障记录”提供本次运行的 p50、p95、最大值和样本数，每类保留最近 60 个样本。允许的指标名固定，数据不会自动上传，也不会保存 URL、凭证、账号、搜索词或请求内容。

| 指标 | 单位与口径 |
| --- | --- |
| `home_cold` / `home_warm` | 页面显示到首份目录数据提交 Vue 更新后的毫秒数；温启动已保留内容可立即就绪。不是完整首屏图片绘制时间。 |
| `api` / `catalog_api` | 成功 API 的单次网络尝试耗时；不含失败重试前的退避时间。 |
| `asset_wait` | 资源加入队列到获得槽的毫秒数。 |
| `asset_download` | 成功下载开始到完成的毫秒数。 |
| `asset_bytes` | 单次成功下载的已知文件字节数，不代表会话总流量。 |
| `reader_image` | 当前阅读页开始获取图片到 image load 的毫秒数，包含下载/缓存读取与加载。 |

## 验证

- 单元/组件测试覆盖资源优先级、共享下载提升、立即取消、字节容量淘汰、跨登录公共请求复用、游标分页与失效恢复、120 页前后连续导航和指标有界性。
- 后端测试覆盖每页缩略图大小、旧资料补齐、幂等性、权限收紧、顶层难度及游标总数/搜索记录。
- `tests/mini-performance-ui.mjs` 在本地测试构建上验证 8 张轮播仅加载 2 张、登录前后公共配置只请求一次、40 页容器/图片上限、跨组选页、按钮翻页及触摸滑动；产物在 `artifacts/mini-performance/`。
- 原有通用与真实接口回归分别运行 `tests/mini-optimization-ui.mjs`、`tests/mini-discovery-ui.cjs`。真实接口脚本只接受隔离 fixture；H5 验证构建需用进程变量 `VITE_API_BASE_URL=http://127.0.0.1:8365`，勿修改线上环境文件。
- 微信包结构检查和 H5 浏览器测试无法替代真机。低端安卓/iOS 的滑动帧率、原生解码内存、弱网耗时及外部 PDF 查看器仍需设备实测；本轮不宣称未经测量的整体提速比例。

本轮本地结果：前端 188 项测试、后端 114 项测试及 10 项子测试通过；通用浏览器 11 项、真实接口 8 项、性能场景 3 项检查通过，无浏览器运行异常。TypeScript、ESLint、Ruff、依赖覆盖检查及两端构建通过。微信主包 729.5 KiB / 2048 KiB，总包 825.2 KiB（332 个文件）。合成习题样本的原图为 85,063 字节，选页缩略图为 11,619 字节，此样本大小不代表所有资料。

测试报告：`artifacts/mini-performance/result.json`、`artifacts/mini-perf-discovery/ui-result.json`、`artifacts/mini-optimization/browser-result.json`。单元与后端日志为 `artifacts/mini-perf-tests.log` 和 `artifacts/mini-perf-backend.log`。
