# 后台添加习题流程

## 文件清单

“公共习题 → 添加习题 → 手动导入 PDF”支持多次选取文件。每份文件有独立标识、标题、年级、科目、分类和 PDF 内容类型；同名不同内容的文件可以分别导入、移除和重试。批量填写只作用于尚未创建草稿的文件，不覆盖已成功结果。

选取时检查扩展名、PDF 文件头、空文件、32 MB 上限，以及本次清单中的内容重复。重复判断基于 SHA-256，文件名不作为唯一标识。40 页限制、加密或损坏的 PDF 仍由服务端解析时校验；客户端校验不能替代服务端校验。

清单保留在当前后台页面会话中，切换模块会停止后续任务；刷新或关闭页面后需要重新选择文件。已创建的草稿保存在服务端。

## 图片合成 PDF

“公共习题 → 添加习题 → 上传图片生成 PDF”可一次或分次选择多张图片，合并为一份 PDF 后上传并创建一份草稿。每张图片占一页，按清单顺序排列；提交前可上移、下移、顺时针旋转或移除图片，并填写公开标题、年级、科目、分类和内容类型。

- 支持 JPG/JPEG、PNG、WebP；最多 40 张，单张不超过 20 MB、5000 万像素，原图合计不超过 200 MB。空文件、格式不符或无法解码的图片会显示错误，移除后可继续。
- 每页使用 A4，横竖方向随旋转后的图片调整。图片等比居中、保留 5 mm 页边距、不裁切，透明区域填充白色。浏览器按照片方向信息解码，最长边缩至最多 3508 像素，以高质量 JPEG 嵌入 PDF。
- 合成在浏览器本地逐页执行并显示进度。最终 PDF 不超过 32 MB；合成失败保留图片清单，可调整后重试。切换后台模块会停止合成，刷新或关闭页面后需重新选择图片。
- 合成成功后自动进入 PDF 导入清单，只上传本次生成的一份 PDF。上传失败保留该 PDF，可直接重试；原图清单在合成成功并加入导入清单后清空。
- 合成仅整理图片，不识别题目或生成答案。创建后沿用预览、教学标签、答案附件和确认发布流程。

服务端按页面尺寸缩放预览，使横向和大尺寸 PDF 的预览图都保持在 1200 × 1800 像素以内，原始 PDF 文件保持不变。

## 导入与恢复

- “导入待处理文件”只处理校验通过的待导入项；“仅重试失败项”保留每份原有标题和属性，不重传已成功文件。
- 上传显示实际字节百分比；上传完成后显示“正在生成预览”，收到成功结果后才标记“草稿已创建”。总进度表示已处理文件数。
- “停止后续导入”保留当前已发出的请求，后续文件和未发送的答案附件停止；可继续导入待处理文件或单独关联答案。
- 每份文件都可附答案 PDF。答案关联失败时，习题草稿仍成功保留；只重试附件即可，成功后同步条目版本号。
- 登录失效会停止后续导入。网络错误或超时可能发生在服务端已保存之后，此时先检查公共库；服务端仍会拒绝同一归档重复创建公共条目。
- “PDF 内容类型”只描述现有文件，不转换 PDF、不生成或抽取答案。

## 网盘链接与下载方式

添加或编辑习题时，可将“下载方式”设置为“PDF 文件”或“网盘链接”。已有 PDF 或图片合成的习题可以保留预览图，将用户下载按钮改为获取网盘链接；批量导入 PDF 时，每份文件分别设置下载方式。

只提供网盘文件时，选择“公共习题 → 添加习题 → 仅添加网盘链接”，填写标题、年级、科目、分类、完整的 HTTP/HTTPS 分享链接及可选提取码，即可创建草稿，无需先上传 PDF。预览核对后，仍需确认发布。链接与提取码分别填写，不支持将整段分享文案粘贴到链接栏。

- 小程序首页卡片、习题列表及下载记录会标识“网盘资料”；详情页显示“获取网盘链接”，登录并通过权限校验后展示链接与提取码，可一起复制后在浏览器或网盘 App 中打开。无需配置网盘网站为小程序业务域名。
- PDF 模式保留原有下载、打开及打印版本选择；网盘模式不展示 PDF 下载或打印版本选择，已有预览图片继续按观看权限展示。没有 PDF 的网盘资料不显示“文件待上传”。
- 两种方式沿用相同的普通用户/VIP 下载权限。读者列表、详情和角色预览不下发网盘链接或提取码；获取接口每次检查登录、会员与发布状态。下载记录表示请求过 PDF 或获取过链接，不代表已经从网盘完成下载。
- 修改标题等旧客户端请求省略下载方式时，保留原有配置。切换为 PDF 会清除网盘链接和提取码；只有链接的条目需先通过“修订”关联已就绪的 PDF 原稿，再切换为 PDF 下载。
- 数据库启动时补充 `download_mode`、`external_url`、`external_code`，历史习题默认 PDF。纯链接条目保留不含链接的资料元数据归档，以兼容分类、收藏、专题和修订关系；该归档不生成 PDF，也不标记文件已就绪。重启后端即可执行补列。

## 创建之后

创建结果保留“预览并发布”“补充教学标签”“在列表中定位”和“继续添加”入口。预览后进入发布设置，仍需用户明确勾选确认后提交，不自动发布。

编辑支持修改公开标题。每次保存同步服务端返回的版本号、最新标题和列表，支持在同一弹窗继续修改保存。
