# 小程序分享封面

## 问题与修正

旧版所有分享卡片都使用 `static/banners/study.jpg`，即没有标题的蓝色照片。分享路由正常时，卡片仍然看起来没有内容。

按用户要求，分享使用微信默认的当前页面截图。分享回调只返回标题和公开跳转路径，不传 `imageUrl`，也不生成海报或异步封面。

之前尝试过根据资料信息自动绘制封面，并不是手动填写内容，但它并非页面截图，因此已移除该方案的画布、素材及生成脚本。

## 分享行为

- 首页、资料详情、专题及列表转发均使用原生截图；裁剪范围由微信决定，不是整页长截图。
- 标题仍取自对应资料或专题，不需要用户填写；保留公开分享路径和登录回跳规则。
- 列表中分享某份资料，点击卡片仍打开那份资料；个人列表右上角转发仍指向公共首页。
- 原生分享按钮不会在点击时立即移除，以便微信读取按钮携带的资料信息。
- H5 继续使用复制链接，浏览器预览不能模拟微信的原生截图。
- 此修改不新增朋友圈功能。

## 维护与验证

测试验证分享回调不包含任何图片覆盖字段，同时保留正确标题、分享目标及安全回跳：

```sh
pnpm --dir miniprogram test
pnpm --dir miniprogram typecheck
pnpm --dir miniprogram lint
pnpm --dir miniprogram build:mp-weixin
pnpm --dir miniprogram check:release
```

发布检查确保编译后的分享服务不包含 `imageUrl`，不会恢复成固定蓝色图片。

本地测试不等于微信真机验收。需要重新上传并发布小程序后，用新版本重新分享；已发出的旧卡片不会自动更新。发布前应在 iOS、Android 真机确认详情分享、列表分享、加载中分享和取消后再次分享。
