# 后台小红书选题调研

## 创作模块与推荐顺序

小红书工作台在左侧分为四个入口：**内容工作台**、**效果复盘**、**素材库**和**账号管理**。内容工作台顶部依次为“选题调研、选题库、资料制作、笔记制作、发布管理”，各阶段可以自由切换，每次显示当前阶段的页面。资料制作和笔记制作内部继续按步骤组织，效果复盘独立展示。

阶段切换保留各页筛选与关联记录；未保存的编辑在离开前提示确认。原有页面链接仍可直达对应阶段，快速导航可以搜索阶段名称，侧栏搜索会定位到内容工作台。手机端使用横向滚动的顶部导航。

| 模块 | 功能 | 下一步 |
| --- | --- | --- |
| 选题调研 | 搜索采集、筛选、收藏、备注、点赞快照 | 在笔记行点击“转为选题” |
| 选题库 | 目标读者、知识点、需求、原创切入点、资料形式、优先级、计划日期 | 保存并制作资料 |
| 资料制作 | 出题设置、题目/答案/讲解编辑、人工复核、学生卷和答案卷 PDF、可编辑文本 | 保存并制作笔记 |
| 笔记制作 | 标题候选、正文、话题、封面、内页、配色、版本历史、文案与 PNG 素材包 | 保存并安排发布 |
| 发布管理 | 关联笔记或自定义内容、发布前复核、文字与重复提醒、账号排期、文案清单、实际发布登记 | 发布后记录效果 |
| 效果复盘 | 第 1/3/7 天的浏览、点赞、收藏、评论、关注、下载与复盘结论 | 形成下一轮选题 |

第一次使用建议只完成一条链路：采集一个具体知识点，选一条参考笔记转成选题，制作一份资料并复核，再准备一篇笔记。每个模块也能单独新建，并选择关联的上一步内容；一个选题可以对应多份资料，一份资料可以尝试多篇文案。

资料和文案可手动编辑，也可调用后台配置的文字模型。出题复用现有知识范围、质检、限流和用量记录；采集的“一年级”等简称会映射到实际可用的教材年级。不支持的年级科目可以手动制作资料。生成前将请求编号保存在当前账号和资料对应的本机记录中，刷新后通过“查询并取回”读取原结果，避免自动发起重复模型调用。

生成请求同时保存当时的记录版本和编辑内容。生成期间修改并保存，或恢复时版本已变化，结果会保留在“查看保留的生成文案／题目”中；先保存当前编辑，再核对并明确应用。文案应用只替换标题候选、正文、话题与配图文字，保留当前目标读者、切入点、账号档案、配色和备注；题目应用会清除人工复核确认，需重新检查。旧请求缺少版本快照时同样要求核对。刷新后仍可查询原请求，不会重新调用模型。

资料编辑后人工复核状态会重置；保存内容，再检查答案、知识范围和导出排版，最后标为可用。资料与笔记均保留版本历史，历史版本带回编辑区后保存为新版本。并发编辑时拒绝覆盖已更新内容。归档隐藏进行中列表，但保留关联与历史。

配图采用可编辑文字排版，支持三套配色、3:4 比例的 1080×1440 PNG，包含封面及最多八张内页；超出画面容量会提示拆页，不会静默截断。ZIP 内包含文案和按顺序命名的 PNG。PDF 分学生卷和答案讲解卷，文本可另存 Markdown。

内容工作台顶部提供“发图文”入口，点击后直接进入“选图片、写文案 → 预览确认 → 去小红书发布”。第一步可追加本机图片、从素材库选择、调整封面和内页顺序；主页面可直接下拉选择已保存的小红书账号，选中后同时关联编号和昵称，辅助发布默认使用所选账号的浏览器；也可手动填写昵称。选择文件使用可见的原生文件控件，账号加载不会禁用整个编辑区。填写标题、正文和话题即可。记录名称留空会使用发布标题，排期、账号档案和内部备注默认收起。已有工作台笔记仍可关联，并生成配图。发布管理列表也提供“开始发图文”，新手引导可直接进入此流程，无需创建完整示例。

关联发布保存创建时选择的文案快照，之后草稿的改动不自动回写。未发布的计划可点击“更新为最新笔记版本”，更新后重新复核；已发布的记录保留历史版本。复制为新计划会清空实际时间、链接、复盘内容和复核确认。

发布前需要确认版权授权、事实与效果承诺、隐私、实际图片视频、平台规则及所需标识。修改文案、素材说明或发布账号后会重置复核。后端同样校验这些条件；文字规则提醒涵盖夸大承诺、站外联系、互动换取利益、可疑资料来源和个人信息，并比较当前管理员已有记录的相同标题与正文。命中提醒时需填写核实或修改说明。提醒属于启发式检查，存在漏报和误报，不等于平台审核或保证不受处罚；不会识别实际媒体文件，也不会自动改写谐音来规避审核。可通过官方创作百科入口登录后查看当前规则。

排期仅为计划，不会自动向小红书发帖。“复制发布文案”“下载文案与发布清单”和关联笔记配图 ZIP 用于准备素材。用户在官方客户端或创作服务平台自行确认账号、上传素材并点击发布，成功后回填具体笔记链接和实际时间。校验会拒绝未来的实际时间、非笔记的长链接、重复登记的相同链接，以及晚于已有复盘统计时间的发布时间。短链接只校验格式，不自动解析到笔记 ID，因此不同短链接指向同一笔记时仍需人工核对。


辅助发布先选择“账号管理”中的本机账号，复用该账号的独立浏览器。旧版 `%LOCALAPPDATA%\learn-coach\xhs-publisher-profile` 若已存在，会原位登记为“原辅助发布账号”，保留已有登录状态。采集开关不会关闭这个窗口；“新建空白辅助窗口”保留旧页面。它仅操作官方创作页面的“上传图文／上传视频”、文件控件、标题与正文，不点击“发布”、不设置定时发布、不读取或上传 Cookie。此流程仍可能触发平台验证；不能保证账号不受限制。

使用顺序：
1. 第一步选图片并填写文案，点击“下一步：预览确认”，查看实际图片和文字，完成五项复核后点击“确认好了，去发布”。
2. 第三步默认“自己上传到小红书（最简单）”：打开官方发布页，上传原文件或下载有序文件包并解压，分别复制标题、正文和话题，核对后手动发布。也可切换“使用辅助填入”，选择对应的本机账号，打开窗口并核对登录。
3. 辅助填入复用第一步选好的媒体；关联笔记可在第一步点击“生成关联笔记配图”。预览并确认实际素材授权。支持 1–9 张 PNG/JPEG/WebP（每张最多 10 MB、合计 30 MB），或 1 个 MP4（最多 40 MB）。这是本工具的传输限额，不是平台容量声明。
4. 确认窗口账号与本次素材，点击“填入文案与素材”。程序再次读取保存版本并检查；不允许未复核、旧版本或已发布记录上传。
5. 等待平台完成素材处理，人工核对顺序、视频封面、话题关联和商业合作／AI 等标识，再手动点击发布。话题文字会附在正文，实际话题关联需要在官方控件确认。成功后回来登记链接。

保存草稿会记录配图来源、文件名和顺序；素材库文件凭素材 ID 重新读取，本机文件和生成的配图按管理员账号存入当前浏览器 IndexedDB（最多 256 MiB，优先清理旧文件）。刷新或重新打开草稿可恢复图片和顺序，保存、修改文案或切换步骤不清空文件。浏览器缓存被清理、换设备或素材不可访问时，会保留引用并列出缺失项，可重试或移除后重新选择；缺图时不能通过配图检查或辅助填入。本机暂存失败会保留预览并提示下载备份，选择文件不会自动上传到服务器素材库。新增、移除或排序图片会重置发布复核；文案修改和重新保存会重置辅助发布确认。发布成功后，链接与实际时间登记默认收起，可稍后补；“登记为已发布”仅记录实际发布事实，仍要求具体笔记链接。文件传输仅限允许的 Origin，经 `127.0.0.1:17632` 交给官方页面；本机检查数量、大小和文件签名，不支持远程 URL 或任意本地文件路径。传输请求有 58 MB 上限。实际平台上传和媒体解析的结果仍需人工查看。

辅助状态仅表示“等待确认／正在填入／已辅助填入／暂停”，不会自动把发布记录变成“已发布”。登录、验证、控件不明确、已有文案／素材、超长或回读不一致时停止。请求使用来源、随机会话令牌和保存版本绑定；本机保留最近 500 条记录的上传尝试摘要（`xhs-publisher-attempts.json`，仅哈希与时间，不含文案、文件或令牌），避免同一记录在重复点击、刷新或重启后静默重传。失败后先检查原窗口和平台草稿／已发布笔记，确需重开才选择“新建空白辅助窗口”。

2026-10-30 修复官方页面同名模式、副本遮挡和屏幕外副本导致的入口误判，按实际可点击的发布模式定位；尚未上传的关闭窗口可直接恢复，已经尝试上传的记录仍需检查草稿后明确新建。`GET /publisher/preview?account_id=…` 仅在同来源、对应账号、空闲的官方发布页返回窗口画面及控件信息，供核对上传结果；不读取登录数据。

验证：`pnpm --dir admin test` 覆盖媒体校验、来源／令牌、版本复核、并发、失败与重启防重；`pnpm --dir admin test:xhs-assist` 在断开外部请求的 Chromium 模拟页面验证多行文字、图片顺序、视频入口、同名副本和异常停止，并断言发布按钮点击与表单提交均为零。2026-10-30 已在用户选择账号的独立官方窗口完成一张 PNG 的实际上传和文案填入，右侧预览显示图片及文案；未点击最终发布。页面后续变化仍会停止并保留手动导出入口。

发布后的记录可以归档，并保留链接、时间与复盘数据；再次发布应新建记录。版本历史可查看保存时的文案和复核确认，不直接覆盖已发布事实。平台出现验证或限制时应按官方提示处理，不反复重试、刷量或批量重复铺文。

复盘数据由用户从小红书后台录入，按第 1、3、7 天分别保存，并保留实际统计时间。收藏率为收藏/浏览，互动率为（点赞+收藏+评论）/浏览；缺失数据和零浏览量不计算比例。关注和资料下载可留空，不会把缺失值当成零。“待录入”表示已到观察日期且尚未填写数据，仅在工作台展示。

创作内容、版本与复盘数据按管理员账号隔离，使用前端会话的账号请求头校验身份。部署需先运行 `python -m app.migrations` 升级数据库至 `2026111002`，再启动新版服务。迁移为素材增加存储后端、文件键和可空缩略图列，为发布记录增加排期、实际发布时间及查重摘要并回填索引，同时补充采集时间与任务归属索引；保留原有素材、版本和采集数据。旧发布摘要每批 200 条回填，历史图片首次查看缩略图时生成并保存，不在升级时批量解码图片。

新上传的原图和视频保存在 `ARCHIVE_LOCAL_DIR` 下的私有 `xhs/<管理员编号>/` 目录，数据库只保留元数据、引用及小缩略图。下载仍通过登录和归属校验，支持 Range 分段读取，使用 `private, no-store`。旧 BYTEA 原件首次下载时逐条迁移，维护任务每轮最多迁移 5 项：校验原件摘要、落盘同步、读回校验成功后，才在事务中切换引用并清空 BYTEA；失败保留原件并重试，不增加资料版本号。损坏记录不会阻塞其他素材迁移。

升级前先更新备份工具及运维镜像，使其包含当前 `storage_registry.py`、`constants.py` 和 `backup_restore.py`，并完成一次备份/隔离恢复验证。原文件已纳入统一备份、删除队列和孤儿回收；只备份数据库不再包含全部素材。旧 schema 的 BYTEA 仍随数据库备份保存。回滚程序必须支持这版文件引用，不能只修改旧代码的 schema 版本号；需回到只读 BYTEA 的旧程序时，按事故恢复流程处理完整数据库和文件快照，不能直接切镜像。

保存遇到超时或连接中断时，页面先查询原提交；暂时无法查询则保留提交快照，下一次保存先核对结果。之后的新编辑保持在编辑区，原提交确认后提示再次保存。效果复盘使用 `/api/v1/admin/xhs-workflow/reviews/{publication_id}`，发布版本与统计阶段版本均匹配后才在同一事务中保存统计、结论和行动；冲突不会留下部分成功。带入历史版本前展示当前编辑与旧版的字段差异，存在未保存内容时还需确认覆盖。

小红书写入按管理员串行，不同管理员可以并行；共享笔记的快照在数据库中按采集时间原子更新，较旧任务不会覆盖较新快照。进程内等待发生在借用数据库连接前，避免同账号请求排队占满连接池。

后台入口：小红书工作台 → 内容工作台 → 选题调研。管理员可以按年级、科目、可选知识点、发布时间、排序方式和采集条数创建采集任务。每次完成后，后台保留公开搜索卡片的标题、作者、发布时间文本、点赞数和笔记链接。


## 选择采集账号

“选题调研”的采集条件上方可选择账号、刷新列表或进入账号管理。记住本机上次选择；已归档或不存在的账号会清空选择，不自动换到其他账号。采集与账号管理、辅助发布共用所选账号的持久浏览器环境；窗口未打开时会自动弹出。

采集在该账号的新标签页运行，成功后仅关闭自己的搜索页，失败则保留现场供手动登录或验证；已有发布页不导航、不关闭。采集期间同账号不能关闭、归档或辅助填入；其他账号可正常操作。

新任务和整批队列在启动前记录账号绑定。重试和续跑使用任务原账号，不受当前下拉框影响；历史任务找不到本机绑定时要求明确确认。浏览器本地存储保存任务与账号编号（不含登录凭据），本机任务缓存也保存账号编号，并拒绝同任务换号。需要换号采集时创建新任务。

## 多账号浏览器

左侧“小红书工作台 → 账号管理”独立展示本机账号。新增只填写用于区分的账号名称与备注，再点击“打开浏览器”，在小红书页面手动登录；不在工作台填写密码、验证码或 Cookie。可同时打开多个账号，重复点击“唤起浏览器”只唤起该账号已有页面，不重新加载正在编辑的内容。每个浏览器有标明账号名称的说明标签页，名称是本地备注，实际登录身份仍以小红书页面为准。

新账号使用服务端生成的 UUID，各自对应 `%LOCALAPPDATA%\learn-coach\xhs-account-profiles\<UUID>` 的独立持久浏览器配置。Cookie、localStorage、IndexedDB、缓存与登录状态不共用；关闭浏览器或重启本机服务后，再次打开仍使用原目录。浏览器隔离指这些本机数据相互独立，不改变同一电脑的网络出口或硬件环境。

账号清单保存在 `%LOCALAPPDATA%\learn-coach\xhs-accounts.json`，包含名称、备注和版本，不存密码或 Cookie，按本机 Windows 用户和后台访问地址区分。换电脑或换后台域名时不会自动复制账号环境。原采集配置 `xhs-research-profile` 原位登记为“原采集账号”，与“原辅助发布账号”分别保留，采集开关不会关闭账号窗口。

支持名称／备注搜索、改名、归档与恢复。改名不会新建浏览器配置。归档之前需先关闭窗口；归档只是隐藏账号，保留原目录和登录状态，不提供清空 Cookie 或删除浏览器文件的操作。“关闭浏览器”会明确提示先保存编辑；辅助填入期间拒绝关闭、归档或重新唤起该账号，其他账号仍可独立操作。界面的“窗口已打开”只表示浏览器运行状态，不宣称已登录或登录仍有效。

辅助发布的账号选择按发布记录在本机记住。切换账号会清空账号和素材确认；服务端会话令牌、来源和账号绑定，其他账号的令牌不能使用。发布文案中的账号名称仍由用户填写并复核，点击填入前需确认所选浏览器实际登录的账号一致。

验证命令：`pnpm --dir admin test:xhs-accounts` 使用临时目录和拦截全部外部请求的 Chromium，验证两账号的 Cookie、localStorage、IndexedDB、Cache Storage 隔离、关闭重开后的持久数据、窗口复用及辅助发布期间的关闭保护；不会登录真实账号。

## 笔记整理与导出

- 采集任务与批次仅创建者可查看、启动、保存结果、导出和删除；任务列表与总数也只显示自己的记录。公开笔记库和历次点赞快照由管理员共享，转为选题直接读取公开笔记，不依赖其他管理员或已删除的任务。

## 进度、恢复与关键词队列

勾选“批量关键词队列”，每行输入一个关键词（最多 20 行，每行最多 80 字），系统按输入顺序去重。创建后只采集第一项，每次点击“采集下一项 / 重试失败项”只执行下一项，保存后暂停，不再连续采集全部关键词；恢复时跳过已完成项。任一项失败会停止队列，平台网络错误、登录失效与安全验证均需人工处理；仅与本机服务的连接中断会重连一次取回原任务。

默认每项最多 10 条。达到数量上限立即结束，不再多滚动一次；最多执行 14 次读取，连续两次没有新增卡片就结束。需要加载下一批卡片时等待 3 秒，以减少请求密度；这不是平台许可的采集频率，也不保证避免风控。相同后台来源、账号、关键词、时间范围、排序和数量在 10 分钟内复用已有快照，不重新访问平台，保留原采集时间；复用不会延长缓存有效期。

本机采集器版本 10 只能响应可观察的异常，无法读取平台内部的账号风控状态。页面正常且数据返回正常时，不能据此确认账号未受限，也不能保证自动停止隐蔽限制。页面文字检测仅匹配已经显示的非真人操作、账号异常、功能受限、访问异常及安全验证；笔记卡片自身的文字不作为平台提示。主页面以及小红书搜索数据请求返回 HTTP 403/429 时停止，这只说明此次访问被拒绝或请求过多，不直接声明账号被风控。程序被动监听浏览器本来就发出的搜索数据请求，不发送探测请求，不猜测平台未公开的业务错误码。

搜索数据请求失败或首次读取未取得有效卡片时记录 `collection_uncertain`（原因不明），不再滚动反复加载；正常无结果、页面变化、网络故障与隐蔽限制可能出现相同表现，不能可靠区分。筛选或导航超时会再次检查已出现的提示。已知访问拒绝及原因不明均保留原搜索窗口，不把部分结果登记为成功，并自动关闭本机采集器；暂停原因持久化，重启后保持暂停。关闭时仍可打开原账号窗口，恢复前要求人工检查账号、原页面与网络，明确确认可以继续。修改浏览器标识、伪造操作轨迹或处理验证均不属于采集器功能。

## 首次设置

本机采集器在管理员自己的电脑运行，不能在生产服务器运行：小红书搜索结果需要由页面脚本加载，账号会话也只应留在操作员的浏览器中。

1. 在本机项目目录的 `admin` 文件夹安装依赖和 Playwright Chromium：`pnpm install`，然后 `pnpm xhs:collector:install`。
2. 配置 Windows 登录后自动启动：`pnpm xhs:collector:setup`。该命令为当前 Windows 用户创建后台采集器和 WSL 服务启动任务，并在桌面放置“小红书工作台”快捷入口；不需要管理员权限。
3. 首次使用先在“账号管理”新增账号，打开浏览器手动登录。回到“选题调研”选择采集账号；“登录小红书”打开该账号已有窗口。Windows 登录后本机服务会自动后台启动，采集浏览器使用可见窗口。
4. 在后台选择条件后即可开始采集。Windows 重启后需先登录 Windows 账户以触发启动任务；注销、关机期间采集器不会运行。

采集器仅绑定 `127.0.0.1:17632`，只接受明确配置的后台来源（包括本机 `https://localhost`），采集部分只读取页面可见的搜索卡片；辅助发布部分仅在用户操作后填入发布页。账号密码、Cookie 不会发送到后台 API 或数据库。可在 Windows“任务计划程序”中暂停或删除“Learn Coach XHS Local Collector”任务；运行日志保存在 `%LOCALAPPDATA%\learn-coach\xhs-collector.log`。如需允许另一个正式后台域名访问本机采集器，可启动前设置逗号分隔的 `LEARN_COACH_ADMIN_ORIGIN` 精确来源列表。

## 数据范围

只采集公开搜索卡片上的标题、作者、发布时间文本、点赞数和链接。不读取笔记正文或评论，也不点赞、关注、发布内容或绕过安全验证。登录失效或页面要求验证时，由用户在本机浏览器自行处理后重试。

点赞数是采集时的快照，搜索排序和推荐结果会随账号、地区与时间变化，不代表平台全站热度。原始笔记标题和链接始终保留供人工复核。

## 账号定位、日历、素材与入门引导

账号管理的“编辑资料”可维护目标人群、内容方向、文案风格和常用话题。定位档案保存在本机账号清单；在笔记制作中点击“应用账号定位”，生成时将该档案作为输入数据，并随笔记保存快照。后续改名或修改档案不会改写旧文案。发布管理可关联本机账号，日历按账号编号归类；手动填写昵称也可使用。

发布管理支持列表与周日历切换、日期选择、账号筛选和未排期记录。点击计划进入原发布流程。同账号一小时内的排期标为接近，包括周边界附近的记录；这是安排提醒，不代表平台发布频率建议。超过 14 天没有新的实际发布登记会显示提示，仅根据本工作台记录判断。时间按当前浏览器时区显示，排期不会自动发帖。

日历在服务端按所选日期范围和账号过滤，仅额外查询前后一小时以判断边界冲突，不再读取全部历史文案或受历史 5000 条记录限制。未排期计划每页 20 项，显示总数；切换周或账号回到第一页，删除记录后页码自动回退。账号提醒仅使用汇总后的名称与最近发布时间；密集排期返回完整冲突数量及最多 10 个示例编号。

素材库独立展示图片、MP4 和封面模板，可上传、编辑名称与标签、填写来源授权、搜索、预览、下载、归档和恢复。图片最多 10 MB / 2400 万像素，MP4 最多 40 MB；每个管理员最多 500 MB / 1000 项。文件与元数据保存在数据库中，随数据库备份，不能公开访问；重复文件返回原记录，保留原来源和版本。归档不释放空间，需下载备份并明确确认后永久删除。模板保存封面配色、标题和内页结构；套用时保留正文与发布标题。

“待核实来源”的素材可预览下载，核实为本人原创或已授权后才可选入辅助发布；授权素材需要记录依据。来源标记是使用者的记录，不替代授权文件。辅助发布可按选择顺序使用素材库文件，沿用图片数量、视频单独选择、体积和人工确认约束；不会自动提交。文件在辅助页面仍为临时选择，离开页面后需重新选择。

效果复盘的“复盘转选题”根据所选第 1、3、7 天的数据以及已保存结论生成可编辑草稿。比较仅限同账号同阶段；对比少于 3 篇或当前浏览不足 100 会明确提示样本不足。确认后才加入选题库，并保留原发布记录的关联与采样说明，不自动安排发布。

内容工作台顶部的“新手引导”提供六步说明与显式创建的入门示例。示例记录有固定编号，重复创建不新增副本、不覆盖已编辑内容；示例发布计划没有真实链接或发布时间。引导勾选仅表示用户已了解该步骤，按管理员在本机保存，不冒充采集、发布或复盘完成。

## 编辑恢复与日常待办

内容工作台顶部的“今日待办”集中列出待完善／复核、今天及逾期待发布、已到观察时间但未录入的第 1／3／7 天复盘。按本机日期查询，每类分页显示；点击待办进入原记录，复盘待办会定位到对应观察阶段。

选题、资料、笔记、发布与复盘的未保存编辑会按管理员、记录和观察阶段备份到当前浏览器。刷新或关闭页面时提示未保存；重新打开记录后可显式恢复、下载或丢弃本机草稿。后台版本变化时禁止直接恢复覆盖，应下载后核对合并。备份不包含实际媒体文件或登录凭据，不会自动写入后台；存储失败时页面提示立即保存。账号和素材资料再次编辑同一项时也能取回本机备份。

笔记制作的目标读者和写作切入点随笔记保存并带入生成，重新打开可继续使用。列表支持“全部进行中”和“清空筛选”，切换状态回到第一页。

内容工作台用五个阶段展示调研、选题、资料、笔记与发布。内容列表同时显示状态和摘要，资料可见题目数量，笔记可见内页数量，发布记录可见账号与排期。搜索提交后从第一页开始，翻页沿用已提交关键词；加载、空结果和读取失败有独立反馈及恢复操作。选题、资料、笔记和发布编辑页保留顶部保存操作，支持 Ctrl／⌘ + S；弹窗打开、读取中或等待恢复本机草稿时不会触发快捷保存。

调研页始终显示当前搜索条件及采集准备状态，笔记库可展开作者、最低点赞数、排除词和标记筛选，并支持取消已选笔记。快速切换历史任务时以最后一次选择为准。采集器连接检查空闲时每 15 秒一次、忙碌时每 5 秒一次，页面隐藏或离开调研模块时暂停，重新可见时立即检查；未完成的连接检查不会叠加下一次后台轮询。

采集条件默认以紧凑布局集中账号、年级、科目与知识点，时间、排序和数量从“更多筛选”展开；账号刷新和管理入口放在账号字段旁。采集结果的“查看笔记”使用当前选择的采集账号，在其独立浏览器中新开标签并保留链接的访问参数，复用该账号的登录环境。即使采集开关关闭也能选择账号查看笔记。未选账号、账号忙碌或本机服务不可用时会提示原因；此功能需要版本 8 或更新的本机采集器，升级脚本后应重启本机服务。

素材库支持每批最多 20 个文件、合计 200 MB 的多选上传，逐个显示成功、重复、失败或待上传结果。停止在当前文件完成后生效，重试只处理失败和待上传文件。成功上传仍需补充来源与授权。图片列表按可见区域加载经权限校验的 320 像素缩略图，模板显示封面文字与配色，视频仍通过预览播放；原文件不因列表展示而整批下载。批次文件只在当前页面临时保留。

素材文件上传在读取请求体前申请名额，每个后端进程最多同时接收和处理两个文件。繁忙时返回 `429`、`asset_upload_busy` 和 `Retry-After: 3`，前端保留失败文件供稍后重试；客户端取消后，正在执行的处理结束才释放名额，断流或空文件也会正确归还名额。

图片上传时生成 JPEG 缩略图并与原图一同保存；正常列表请求只读取缩略图。历史素材按记录合并首次补生成请求，后续直接复用，不改变素材资料版本；生成进入最多两个并行任务的媒体工作线程。缩略图仍逐次校验归属，响应为 `private, no-store`，原文件保持完整。

效果复盘可按账号和实际发布时间筛选，按发布时间、收藏率、互动率或浏览量降序排列。结束日期包含当天，本机时区转换为请求中的时间区间。后台先筛选和排序全部记录，再分页；缺失指标和零浏览的比例排在最后。

关联内容选择器展示摘要与状态，支持搜索、清空和读取失败重试。翻页沿用已提交的关键词，搜索回到第一页且不会重复请求；末页记录减少时自动回退，加载期间不允许选择旧记录，离开页面后的迟到响应不会覆盖内容。发布日历显示周范围及排期数量，加载时显示占位，失败可重试，只有成功读取后才展示空日或未排期结论；快速切周以最后一次请求为准。

资料与笔记的新建页先选择关联选题或资料，选择前禁用保存并提示前置步骤；没有可选内容时可直接进入上一步创建。顶部阶段入口打开该阶段的列表，继续当前内容使用编辑页的下一步。资料已有未归档笔记时，“保存并继续笔记”进入现有笔记；“另建一篇笔记”显式创建另一份方案。切换记录回到首个编辑步骤，首次保存当前草稿保留所在步骤。

未改变内容的保存保留版本号、更新时间和历史记录，仍校验版本冲突。生成资料前核实教材范围，生成笔记前读取最新关联资料；读取期间切换记录或修改输入会停止此次操作，需重新点击生成。笔记可以展开当前资料的适用范围、使用说明及前三题答案讲解，再打开完整资料核对。

资料的“复核与导出”提供 PDF 预览，可切换学生卷与答案讲解、放大缩小、适应宽度并下载当前预览。预览使用与 PDF 共用排版的分页图片，支持手机浏览，不依赖浏览器的内嵌 PDF 阅读器；修改或切换资料会清除旧分页，迟到结果不会重新显示。空题干阻止资料导出，缺答案或讲解阻止答案卷导出；空封面、空白内页或缺发布正文会提示补全，避免导出空内容。复制文案失败时下载点击时的文案快照。

修改资料的年级、科目、知识点、题型、难度、题数、题目或使用说明会清除三项复核；先保存内容，再重新勾选。笔记生成记录所用资料版本，资料更新后提示核对，刷新关联资料不会改写现有文案。生成期间来源版本变化时保留结果供人工核对，确认应用旧版文案后仍显示版本差异；历史文案没有版本记录时明确提示核对。配图修改或切换笔记会清除旧预览，迟到的预览不会写入其他内容；预览、模板保存和导出使用点击时的内容快照。

笔记库始终显示已应用的标题、作者、点赞、排除词与标记等筛选条件，收起筛选后仍可核对，尚未提交的输入不会改变提示。已选笔记跨页保留，切换筛选或范围后清除。关闭编辑弹窗时，未保存的标记和备注会提示继续编辑或明确放弃。发布图片添加和调序复用现有预览，移除只释放对应文件，离开页面释放剩余预览。
