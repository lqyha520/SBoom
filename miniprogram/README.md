# 公共习题小程序

独立的消费者客户端，面向普通用户和 VIP 会员。小程序账号、登录会话、收藏和下载记录均与出题工作台分离。
出题、排版和私人归档仍由 `web/` 负责，发布和会员运营由 `admin/` 负责。
小程序没有私人习题空间、私人文件夹、删除归档或绑定工作台账号的入口。

## 技术与目录

`miniprogram/` 有独立的依赖、锁文件、Vite 配置和构建输出，仅通过 HTTP 调用 FastAPI，不导入网页 UI。

- uni-app Vue 3 CLI `3.0.0-5020420260813003`，编译器 5.24。
- Vue 3.5.42、TypeScript 6、Wot UI 2.3.2（`@wot-ui/ui`）。
- uni-app 当前编译链要求 Vite 5.2.8 和 vue-i18n 9，不单独升级某个 `@dcloudio/*` 包。
- 微信使用原生请求、临时文件、滑动/缩放组件和 PDF API。支持选择后台关联的练习版/答案版 PDF，不在小程序内重排题目。
- 控件统一使用 Wot，主题在 `src/theme.scss`；不是复制的付费商业模板。
- 登录页使用本地 3dicons 笔记本插画；与保留的分享照片、Lucide/Wot 图标授权一起见 [THIRD_PARTY_NOTICES.md](./THIRD_PARTY_NOTICES.md)。首页运营图片来自后台上传。

```text
src/pages/        home, library, favorites, downloads, recent, account, paper, login, topic
src/subpages/     membership, support, orders, privacy, requests, messages, closure（服务页分包）
src/components/   Banner、自定义导航、会员弹层、鉴权图片、习题卡片、搜索筛选、收藏分组
src/services/     API、消费者会话、文件生命周期、偏好与搜索记录、登录返回、消息、支付与请求顺序保护
src/static/       插画、Banner、标签栏图标、字体、授权声明
tests/            页面契约、首页分组、筛选、文件和请求回归
scripts/          素材生成、微信包检查、发布配置检查
```

底部为「首页 / 习题库 / 收藏 / 我的」，采用四等分导航，选中图标显示浅绿色底色，点击区域高 46px。底部安全区与最小下边距取较大值，不额外叠加留白。原生 tabBar 保留路由配置但隐藏，
仍使用 `switchTab`；多个弹层同时存在时，最后一个关闭后才恢复自定义底栏。所有页面使用自定义导航，
`PageChrome` 在微信端预留状态栏和系统胶囊区域，H5 不显示多余标题。首页从搜索和年级选择开始，不再额外展示品牌标题与宣传语。无 Banner 时使用紧凑引导，登录用户有浏览记录时可继续查看最近资料；公告默认收起正文，可点击展开。主要辅助文字不低于 12px，同类底部弹层采用 22px 顶部圆角，自定义按钮使用统一按压反馈。

首页按所选年级请求最多 12 份真实习题，每次展示 2 份，可以换一组；
首页和习题库共用年级选择面板，小学年级在紧凑入口中简写为“一年级”等，完整名称仍用于筛选与请求。搜索框统一为 12px 圆角，列表卡片使用 16px 圆角；主标题优先于辅助信息，免费资料用浅绿标识，会员资料用浅金标识，首页、列表和详情保持一致。
最近搜索单行横向滚动；无搜索结果时可以只清除关键词，保留已选年级与其他条件。个人中心在 360px 以下使用两列服务入口。详情底栏的收藏、分享都有文字说明，下载保持为主操作。
「为你精选」使用后台精选排序，「最近上新」使用 `sort=latest` 按发布时间排序。
收藏、下载和最近浏览列表按账号操作时间排序。列表侧滑仅展开操作区，点按钮后才执行；也可点“更多资料操作”，同一时刻只展开一行。微信使用原生按钮分享单份公共资料，H5 可复制资料链接；“查看资料”直接进入详情。习题库另有最新、热门和仅免费筛选；免费要求原稿观看和 PDF 下载均对普通用户开放。
Banner 使用后台配置，没有可见 Banner 时只显示一个选题入口，不插入固定轮播。专题合集由后台编排资料及顺序，在首页和列表筛选中展示。
习题库年级入口提供独立快速选择，更多筛选收纳分类和有可选内容的教学标签；搜索输入停顿 300ms 后检索，确认搜索立即生效，离开页面会取消待执行搜索。分类、专题和标签独立加载与重试，成功结果缓存60秒，下拉刷新会更新。列表缩略图接近视口后才获取文件。
首页年级与科目入口会清除无关筛选；专题合集按编排顺序进入。年级、科目偏好和最近 12 条搜索在本机按账号保存，搜索可清空。
游客选择的年级在本次首页会话内保留。切换精选/最新只刷新习题；首页推荐、分类或专题单独失败时显示重试入口，已成功加载的内容仍可使用。
公开首页与习题库可在登录恢复完成前加载；公开请求不携带账号凭据，个人操作仍等待会话确认。首页加载期间可切换年级与推荐排序，旧请求会取消；从详情返回后保留当前推荐组和滚动位置，并刷新权限。详情明确标注原稿预览，下载按钮显示当前选择的文件版本。列表排序和免费筛选的点击区域至少为 44px。

### 首页 Banner 管理

已提供三套可编辑的[学习专题运营素材](./marketing/study-collection/README.md)，包含 1200 × 500 Banner、900 × 600 专题海报和配套运营文案。运行 `pnpm --dir miniprogram assets:editorial` 可从现有授权素材重新生成。素材在后台上传，不额外增加微信主包体积；首页专题卡片复用已有笔记本插画，标题与资料数仍由后台返回。

后台入口：**小程序管理 → 首页 Banner**。新建或编辑时可直接选图，查看手机预览，设置文案、点击去向、排序和上下线；点击「保存 Banner」后生效。新建时如果上传失败，该条保持下线，选中的文件保留以便重试；取消编辑不会上传文件。

- 图片区比例为 **12:5**，推荐 **1200 × 500**，支持 JPG / PNG / WebP，文件不超过 2 MB，尺寸不超过 2400 × 1600。
- 「完整展示」保留整张图片，比例不同时留出浅灰边；「居中裁切」铺满图片区，适合照片。配图不叠加固定绿色遮罩；标题、副标题和按钮统一放在图片下方。
- 文字卡片也可独立使用。「不跳转」不会显示按钮或触发导航；关键词、分类、学科和指定习题可整卡点击，指定习题支持直接搜索选择。
- 更新图片后首页接口返回带版本的资源 URL；前端按 URL 更新文件引用，重新进入首页或下拉刷新后即可看到新图。移除图片和下线也会释放旧文件。
- 浏览器联调：启动独立的 `tests/profile_ui_fixture.py --port 8361 --seconds 1800` 后执行 `node tests/home-banner-ui.cjs`。脚本先校验 `fixture: true`，只操作临时测试数据。

详情首屏展示原稿封面和文件信息；全屏原稿支持横滑翻页、双指缩放、上一页/下一页和页码跳转，只挂载当前页及相邻页的鉴权图片。按账号、资料和发布版本在本机记住最后阅读页码，最多保留 50 份，不保存鉴权 URL；关闭重开或刷新后可继续阅读。
所有图片均来自受权限保护的真实原稿，不用演示插图替代习题。未知题数以页数或 PDF 资料兜底，避免显示“0 题”。下载权限在主按钮旁明确说明，练习版/答案版选择、传输进度与重试提示集中在底部操作区。PDF 操作保留微信原生打开与 H5 下载分支。详情底部固定操作栏提供分享入口：微信调起好友分享，H5 复制公共资料详情链接并提示结果。
「我的」顶部直接展示头像资料，提供会员状态、订单、消息、资料需求、收藏、下载、最近浏览和客服入口；退出登录和注销申请通过下方“账号与安全”进入。
编辑资料支持微信主动选头像或 H5 图片上传，并提供 5 个本地默认头像。选图期间保留草稿，先压缩再上传，失败后可以重试；头像与昵称一起保存。
资料详情可关联提交纠错或下载问题、调整收藏分组，并查看修订版本与更新说明。收藏分组弹层可直接新建并归组；若仅归组失败，保留已创建分组供点选重试，避免重复创建。收藏页分组横向滚动。最近浏览最多保存 100 份，清空不会取消收藏。

## 账号与会员权限

H5 和微信均使用独立消费者 Bearer 会话，不使用工作台 Cookie。后端只保存 token 摘要。
新注册与修改密码至少8位，历史6位密码仍可登录。
H5 的账号登录/注册表单位于底部弹层，使用 `/api/v1/mini/register` 和 `/api/v1/mini/login-password`；
微信端仅显示「微信一键登录」，以 `uni.login` 获取真实 code 后调用 `/api/v1/mini/login`。
浏览器不能模拟小程序微信授权；两端均默认不勾选协议，登录中的重复点击和离开页面后的迟到响应不会触发跳转。
用户协议与隐私政策在登录前即可读取后台正式内容；网络失败时明确显示离线说明。
`username` 是固定登录账号，`nickname` 是可重复的展示昵称。用户或后台修改昵称均不会改变密码登录所用账号。
新微信账号为 `wx` 加 10 位数字，默认昵称为 2-4 个中文字。新注册及后台新建账号只接受英文、数字、下划线与短横线，历史中文登录账号继续兼容。
`MINI_REGISTRATION_ENABLED=false` 关闭小程序注册和微信首次开户，不影响出题端 `REGISTRATION_ENABLED`。

后台入口：

1. **小程序用户**：账号/昵称搜索、7 天内到期与已过期筛选、30/90/365 天快捷续期、会员及账号操作记录。
2. **题型权限**：分别设置完整原稿观看和 PDF 下载权限。免费预览允许游客查看，PDF 下载需登录，VIP 权限继续生效。
3. **公共习题**：权限配置、批量分类/发布/下架/权限、普通用户/VIP 预览、保留条目身份的原稿修订。
4. **服务与反馈**：联系渠道、权益说明、用户问题、公开回复、内部备注及处理状态。
5. **专题合集 / 内容数据看板**：编排专题，查看活跃人数、无结果搜索和下载结果统计。
6. **教材与知识点 / 资料需求**：管理教学标签，汇总需求并关联补齐资料；公共习题可配置同题练习、答案文件。
7. **会员套餐 / 会员订单 / 账单核对**：管理价格、上下架、支付状态、全额退款及交易差异。
8. **注销申请 / 订阅提醒**：审核注销、检查发送配置及微信提醒结果。

同一份资料有多个题型时，继承规则取最严格权限。VIP 观看必然要求 VIP 下载，不能用 PDF 绕过观看限制。
支持「普通用户可预览，VIP 才能下载」。逐份明确覆盖优先于题型规则；只改标题不会重置原权限。
会员到期自动失效，后台撤销会员不需要重新登录；禁用账号撤销全部会话，重新启用后需要重新登录。
会员修改带 revision 冲突检查并保留审计记录。支付默认关闭；配置微信商户后，可由后台上架套餐，在微信端下单、支付和申请全额退款。不提供自动续费。
有效会员续期从原到期日累加，过期或普通用户从当前时间开始；长期会员无需续期，禁用账号续期后仍保持禁用。
小程序会员弹层显示权益、联系入口及 7 天内到期提示；管理员回复可在「服务与反馈」查看。
会员服务页将客服放在首屏和固定底栏，联系面板支持复制、拨号、二维码和留言。套餐点选只改变选择，确认后才创建订单；不支持支付时可咨询开通或兑换卡密，长期会员不会重复开通。
支付以服务端微信验签结果为准；退款只撤回相应订单未使用的会员时长。H5 不提供微信付款，默认 iOS 也不提供在线开通。
消息按账号隔离，支持已读、未读和业务结果跳转；微信订阅提醒需配置模板且由用户主动接受一次订阅。

普通账号仍可浏览 VIP 习题的标题、分类和标签，也可收藏，但不能拿到受限的题目快照、答案、缩略图、预览图或 PDF。
文件直链也实时检查会员、发布状态和文件归属，不能靠隐藏前端按钮实现权限控制。
下载记录表示请求过 PDF，不保证设备已经另存成功；已保存到设备的文件不能因到期或下架而撤回。

## 本机开发

需要 Node.js 22.12+、pnpm 10.14 和运行中的后端。

```bash
pnpm --dir miniprogram install --frozen-lockfile
pnpm --dir miniprogram dev:h5
```

默认地址 `http://127.0.0.1:5180`，API 代理到 `http://127.0.0.1:8000`。H5 推荐同源代理：

```dotenv
VITE_API_BASE_URL=
VITE_BACKEND_URL=http://127.0.0.1:8000
```

本机配置在 `.env.local`，已被 Git 忽略，不要直接用模板覆盖。端口占用时指定 `--port 5181`。
执行 `build:h5` 后，将 `dist/build/h5` 部署到独立域名根路径并反向代理 `/api`。

### 持久化联调

日常使用应启动根目录 `python run.py`，并将小程序 `VITE_BACKEND_URL` 指向
`http://127.0.0.1:8000`。后台地址为 `http://localhost:8000/admin/`，出题工作台为
`http://localhost:8000/`，小程序 H5 为 `http://localhost:5180/`。
三个入口共用根目录 `.env` 配置的数据库；配置了 `DATABASE_URL` 就使用 PostgreSQL，
没有配置时才使用 SQLite。小程序用户与出题用户仍然是不同的表和登录体系。

账号、会员、题型/资料权限、发布状态、收藏分组、下载记录、最近浏览、反馈、专题、标签、需求、消息、注销、订单、退款和修订历史保存在数据库中；
本地 PDF/JPEG 保存在 `data/paper-files/`（或 `ARCHIVE_LOCAL_DIR`），数据库保存文件索引与校验值。
正常重启不会重新生成账号或清空数据，也不会自动导入演示内容。Banner、联系信息和专题由后台配置。

已有临时演示数据的明确迁移流程见 [本地运行与数据迁移](../docs/local-runtime.md)。
正式后台继续使用原管理员账号，隔离演示的 `admin_console` 不能用于正式数据库。

## 微信发布

1. `src/manifest.json` 的 `mp-weixin.appid` 设置真实微信 AppID。
2. `.env.production.local` 设置 `VITE_API_BASE_URL=https://你的API域名`，仅填源地址，不含路径或 AppSecret。
3. 后端 `.env` 配置相同的 `WECHAT_APP_ID`、对应的 `WECHAT_APP_SECRET`。
4. 使用 HTTPS，启用 `FORCE_HTTPS=true`，配置微信 request 和 downloadFile 合法域名。
5. 将构建产物导入微信开发者工具，在真机验证登录、VIP 权限、图片预览及 PDF 保存。

```bash
pnpm --dir miniprogram typecheck
pnpm --dir miniprogram test
pnpm --dir miniprogram build:h5
pnpm --dir miniprogram build:mp-weixin
pnpm --dir miniprogram check:mp
pnpm --dir miniprogram check:release
```

`check:mp` 检查当前注册页面的 JS / JSON / WXML / WXSS、资源、组件、原生 PDF 分支和小于 2 MiB 的主包，并禁止私人页面和绑定入口；本版共 16 个页面。它也会拦截微信不接受的 `.row > :last-child` 等组合符后直接跟伪类的写法，应使用明确的类选择器。

安装微信开发者工具后，可将环境变量 `WECHAT_WCSC_PATH` 设置为工具安装目录下 `resources/app.asar.unpacked/node_modules/wcc-exec/wcsc.exe` 的绝对路径，再运行 `check:mp`。检查将额外调用微信样式编译器，逐一验证全部 WXSS；普通 uni-app 构建成功不等于微信样式编译通过。
仅使用公共组件样式的页面也会在构建时生成空 WXSS，避免微信开发者工具热重载读取页面样式时出现 `ENOENT`。已有页面样式会原样保留。
`check:release` 额外检查真实格式的 AppID 和已编译的 HTTPS 源地址。缺少配置时应失败，不能关闭域名校验。
主包大小以实际构建检查输出为准。编译/API/H5 测试不代表微信真机登录、设备文件保存或审核发布已经完成。

素材可分别通过 `pnpm --dir miniprogram assets` 与 `node miniprogram/scripts/build-notebook.mjs` 重建。
后者使用固定版本的 CC0 来源，生成 512 像素本地 PNG，不增加运行时外链依赖。
五个默认头像为本项目绘制的本地图片，可通过 `node miniprogram/scripts/build-profile-avatars.mjs` 重建。

## 旧版升级

## 弱网与操作恢复

完整的 [16 页审查与优化记录](../docs/mini-all-pages-2026-09-19.md) 包含逐页结论和截图索引。服务类页面的插槽卡片样式统一放在应用级 `styles.scss`；资料需求和反馈通过分段入口切换提交与历史记录，从消息进入时直接显示对应进度。

- 冷启动恢复登录时，断网、超时或服务端临时错误保留凭证；账号入口显示“重新连接”，恢复后重新加载当前页面。只有明确的登录失效或账号停用/变化才清理登录凭证。
- 下一页加载失败在列表底部重试同一分页，不清空已加载内容；加载期间仍可打开资料。收藏按行显示忙碌状态，与列表请求独立；筛选变更回到新结果开头，旧响应不覆盖新筛选或收藏状态。
- 打开消息立即跳转，同步已读在后台执行，并即时更新未读提示。失败显示重试同步入口；再次进入消息中心会重试。待同步回执仅存于当前运行内存，切换账号后隔离，退出应用后由服务端状态重新加载。


## 缓存、分包与验证约定

- 服务页位于 `src/subpages/`，从“我的”进入时在 Wi-Fi 下预加载；`safeDestination` 将旧 `/pages/` 服务链接转换到新路径。Tab、资料详情、专题和登录保留在主包。
- 公开运营配置缓存 60 秒；按登录代际隔离的个人摘要、用户信息和未读数缓存 20 秒，写操作前后均失效。GET 网络/网关失败重试一次，支付及其他写操作不自动重发。共享错误类型保留 `X-Correlation-ID`。
- 图片释放后最多保留 45 秒、40 个空闲文件；内存告警清理空闲文件，退出或切换账号清空全部资源。列表只有一个可见区域观察器，每组最多保留 60 行，通过上一组／下一组继续浏览；返回时核验保留行的权限，未变化行复用引用。批量整理的“全选已加载”仅选择当前组已加载内容。
- 原生支付返回后以原账号完成服务端确认，最多同步三次；确认期间隐藏再次付款入口。真机收银台、外部查看器和平台隐私授权仍需使用测试账号验收，自动测试不发起真实付款。
- `pnpm assets` 从源码、分类图标白名单和实际使用的 Wot 组件生成离线字体子集。分类白名单见 `src/services/category-icons.ts`；未知名称显示回退图标。Notebook 使用 384px 调色板 PNG。
- 提交前执行 `pnpm typecheck`、`pnpm lint`、`pnpm test`、`pnpm check:overrides`、`pnpm build:mp-weixin`、`pnpm check:mp`、`pnpm build:h5`。`pnpm-workspace.yaml` 为每个依赖覆盖列出上游来源；升级 uni-app 后检查覆盖目标仍在 lockfile，并移除过期覆盖。
